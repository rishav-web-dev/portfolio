# 🚀 Rishav's Personal Portfolio

Welcome to the repository for my personal web developer portfolio! This site acts as a central hub to showcase my latest projects, technical skills, and journey as a developer. You can view the live site at **[rishav-web-dev.github.io/portfolio](https://rishav-web-dev.github.io/portfolio/)**.

## ✨ Features
* **Modern UI/UX:** A clean, responsive design that scales perfectly across desktop and mobile devices.
* **Dark Mode Ready:** Includes a dedicated dark theme toggle for viewing comfort and accessibility.
* **Performance Optimized:** Built with clean code, fast load times, and smooth transitions in mind.
* **Project Showcase:** A dedicated space to highlight my journey, skills, and current web builds.

## 🛠️ Tech Stack
Here are the core technologies I work with to build and run my projects:
* **Frontend:** React.js, HTML5, CSS3
* **Backend:** Node.js, Express.js
* **Environment:** Developed and configured locally, utilizing Termux on Android for mobile development stacks.
